# Roadmap

- Show task queue, progress, and user-selected output locations.
- Support local-account sign-in and task management.
- Export completed extraction results as Excel workbooks.
- Configure LLM providers from environment variables or an encrypted settings panel.
- Manually requeue unfinished documents after a Worker or queue interruption.
- Run multiple versioned workflows with dynamic configuration and normalized result envelopes.
- Extract material properties, user-defined records, or typed entity relationships.

- Preserve page/block coordinates during PDF parsing for stronger evidence navigation.
- Add human verification states and schema-aware result editors.
- Publish a Python package, MCP server, or Codex skill that submits extraction jobs to the
  hosted Deep Dig backend without exposing provider credentials.
